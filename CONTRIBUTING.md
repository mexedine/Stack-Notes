# Contributing to Stack Notes

Thanks for your interest in improving Stack Notes.

## Project principles

- Keep the app offline-first and local-first.
- Preserve user data on-device; do not introduce cloud dependencies or telemetry without an explicit project decision.
- Prefer vanilla HTML, CSS, and JavaScript, consistent with the existing stack.
- Keep the app lightweight and avoid unnecessary dependencies.

## Before submitting a change

1. Explain the problem the change solves.
2. Keep changes focused and avoid unrelated rewrites.
3. Test affected features on the target Android wrapper and in a browser where practical.
4. Check that existing notes and locally stored data remain intact.
5. Document any new behavior or limitations.

## Pull requests

Describe the user-visible change, list the relevant tests performed, and call out any migration or data-loss risks.
