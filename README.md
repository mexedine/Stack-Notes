# 📝 Stack Notes

A premium, offline-first note-taking app built for people who want their data to stay on their device. 

**No accounts. No cloud. No tracking. Just pure, offline software.**

## ✨ Features
*   **Zero Dependencies:** Built from scratch in vanilla HTML/CSS/JS. No React, no bloat.
*   **Templates:** Cornell notes, weekly planners, habit trackers, and more.
*   **Sketch Canvas:** Draw diagrams or handwriting directly inside your notes.
*   **Advanced Search:** Find notes instantly using `#tags`, `nb:notebook`, or `is:pinned`.
*   **Local-First:** Everything is stored securely in your browser's IndexedDB.
